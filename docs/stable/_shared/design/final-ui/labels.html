Interactions summary

  • Inline create row at top — swatch (click opens the color popover: 12 presets + custom hex) + name input + Enter to create. Default color is hash-derived from the name and recalculates as the user types, freezing on the first manual pick. After create, the row clears and stays focused for rapid creation.
  • Click name in a row → edits in place with ✓ / ✗ commit buttons (single-tap-to-edit; lighter than the pencil pattern used for task titles).
  • Click swatch in a row → opens the color popover; commits immediately on selection.
  • Click task count or Filter → → navigates to All-tasks with the label preselected (/tasks?labelId=<id>).
  • Delete → modal with the two soft-delete modes above; "Keep task links" is the default.
  • Restore (deleted view) → label reappears; whether its tasks are still tagged depends on the mode picked at delete time.
  • Permanently delete (deleted view only) → hard delete after a second confirmation; remaining task links are cascade-removed. No recovery.
  • Sort → toggle "Sort: usage ↓ / name ↑ / recent ↓". Persisted via URL.
  • Filter by name → client-side string match across the loaded list.

Mobile: same single-column table; row actions collapse into a ⋯ menu below the md breakpoint; the color popover renders as a bottom sheet.
